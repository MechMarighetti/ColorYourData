CONSENTIMIENTO INFORMADO Y TÉRMINOS DE USO

Proyecto: "Encuesta de Color Favorito y Huella Digital"

  1. Propósito del Proyecto
    Este sitio web es parte de un proyecto educativo desarrollado por el Grupo F para la materia Trabajo, Tecnología y Sociedad de la Tecnicatura en Desarrollo de Software del IFTS 18.
    El objetivo de este proyecto es demostrar, con fines exclusivamente académicos, la cantidad y el tipo de información que un sitio web puede recopilar de un usuario durante una interacción tan simple como responder a la pregunta "¿Cuál es tu color favorito?". Nuestra intención es crear conciencia sobre la huella digital y la importancia de la privacidad en línea.
  2. Datos que Recopilamos
    Al utilizar este sitio y enviar tu respuesta, nos autorizas a recolectar y almacenar los siguientes tipos de datos:
    Dato de la encuesta: Tu color favorito seleccionado.
    Datos técnicos del navegador (recolectados pasivamente): Incluyen, pero no se limitan a: tu dirección IP, tu User-Agent (tipo de navegador y sistema operativo), resolución de pantalla, zona horaria, idioma del navegador, y una "huella digital" anonimizada (un identificador único generado a partir de la configuración de tu navegador, como las fuentes instaladas o capacidades gráficas).
    Datos de geolocalización: La ubicación geográfica aproximada (país, región/ciudad) inferida a partir de tu dirección IP.
    Datos de ubicación precisa: Si lo permites, se puede acceder a tu ubicación geográfica precisa (latitud y longitud) a través de la API de geolocalización del navegador. Este permiso es opcional y solo se solicita al guardar tu respuesta. Puedes denegarlo en cualquier momento desde los ajustes de tu navegador.
    Datos de comportamiento opcionales: Si das tu consentimiento explícito marcando la casilla correspondiente, también recolectaremos datos sobre tu interacción con la página, incluyendo el tiempo que tardas en seleccionar un color, el número de clics en colores antes de la selección final, un patrón simplificado de movimientos del mouse dentro del área de la encuesta, el porcentaje máximo de la página que has visto mediante scroll, y el número de pausas en el scroll (momentos en que dejas de hacer scroll por más de 1.5 segundos). Estos datos se utilizan únicamente para demostrar aspectos de la huella digital relacionados con el comportamiento del usuario y son completamente opcionales.
  3. Finalidad del Tratamiento de Datos
    La única finalidad de la recolección de estos datos es asociarlos de forma anónima con tu color favorito elegido para generar estadísticas agregadas y visualizaciones, y para demostrar el proceso técnico de recolección de datos. Los datos no serán utilizados para ningún otro fin, especialmente no para fines comerciales, de perfilado individual o de identificación personal.
  4. Anonimato y Seguridad de los Datos
    Los datos serán almacenados de forma segura en una base de datos cuya única finalidad es este proyecto. Una vez finalizado el proyecto, la base de datos será eliminada. No se te pedirá información personal identificable (como nombre o correo electrónico). Los datos se tratarán de forma agregada para las estadísticas y nunca se publicarán datos individuales. Almacenamos tu dirección IP únicamente para inferir la geolocalización, pero garantizamos que no será utilizada para identificarte personalmente.
  5. Uso de Cookies y Tecnologías Similares
    Este sitio puede utilizar tecnologías de almacenamiento local (como localStorage o sessionStorage) para guardar temporalmente tu respuesta o el estado de los permisos durante tu visita. No se utilizan cookies de rastreo de terceros.
  6. Carácter Voluntario
    Tu participación es completamente voluntaria. Eres libre de no aceptar estos términos y abandonar el sitio en cualquier momento.
  7. Contacto
    Para cualquier consulta, puedes contactar al Grupo F del IFTS 18.
